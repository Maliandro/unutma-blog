The dentist appointment is in a text message. The shopping list is on the fridge. A password is in a note called "misc", and the gas bill is somewhere in your email. Nothing is lost, exactly. It is just spread across so many places that remembering where things are has become a job of its own. Most advice on how to organize your life jumps straight to systems and planners. We think the first step is more boring and more useful: count the places.

This guide gives you an inventory table to fill in, a way to decide what moves where, and a 30-day plan to cut the number of places you have to check. It works whether you end up using one app, three apps or a paper notebook.

## Why the number of places matters

Every place you keep information is a place you have to remember to look. Five places means five small chances to miss something each day. The US National Library of Medicine's [remembering tips](https://medlineplus.gov/ency/article/002046.htm) say the same in plain terms: keep essentials in one spot, reduce clutter and use to-do lists. That advice was written for keys and wallets, and it applies just as well to information.

There is a second cost. When things are scattered, you keep a background list in your head of "things I should check". That list is tiring even when nothing is wrong.

## Step 1: the inventory table

Copy this table and fill in the middle column honestly. Include paper, email, screenshots and "in my head".

| Type of information | Where it lives now (all places) | Number of places | Where it should live |
|---|---|---|---|
| Quick notes and ideas | | | |
| To-dos | | | |
| Shopping list | | | |
| Appointments and dates | | | |
| Recurring things (medication, bills, plant watering) | | | |
| Passwords and ID numbers | | | |
| Spending and bills | | | |
| Journal or personal writing | | | |
| "Did I do it?" (door, stove, medication) | | | |

If the "Number of places" column adds up to more than nine, you are checking more places than you have types of information. The goal is one place per row, and ideally fewer places overall.

## Step 2: decide what moves where

Use three rules:

1. **One home per type.** Every row gets exactly one place. Two places for to-dos means neither is trusted.
2. **Sensitive rows get a lock.** Passwords and ID numbers do not belong in a plain note or a screenshot. The US CISA's guide to [strong passwords](https://www.cisa.gov/secure-our-world/use-strong-passwords) recommends a password manager; a separately locked vault on your phone is the minimum.
3. **Shared rows stay shared.** If a list is genuinely shared with your partner, keep it in the shared tool. Do not force it into a personal app.

## Step 3: the 30-day plan

| Week | Move | Leave alone |
|---|---|---|
| 1 | To-dos and shopping list into one place | Everything else |
| 2 | Appointments and recurring reminders | Old notes |
| 3 | Passwords from notes and screenshots into a locked vault, then delete the originals | Archives you never open |
| 4 | Spending and bills; set up a backup | Anything that already works |

Do not move old notes in bulk. Move only what you used in the last month. The rest can stay where it is and be forgotten honestly.

## When one app is the wrong answer

If you work across a laptop and a phone all day, a phone-only app will frustrate you for notes and to-dos. In that case, organise by rows anyway: one place per type, even if the places are different apps. The inventory still works. It is the scattered duplicates that cause the trouble, not the number of apps as such.

## Frequently asked questions

### Where should I start organizing my life?

With the inventory. Write down where each type of information lives today before changing anything.

### Is one app better than several?

One place per type of information is what matters. Fewer apps usually helps, but forcing everything into one tool that does not fit is worse.

### How long does it take to get organized?

About a month if you move one or two rows per week. Trying to do it in a weekend usually ends with a half-moved mess.

### What should I do with old notes?

Leave them where they are. Move only what you used in the last month.

### How do I stay organized after the first month?

A 20-minute weekly review, where you clear lists and check dates, keeps the system from drifting.

## Bottom line

How to organize your life is less about finding the right planner and more about counting where things live and cutting that number down. Fill in the table, give every row one home, lock the sensitive rows, and move one or two rows a week. After a month, there is less to remember about where you remembered things.
